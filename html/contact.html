A02 — The Builder

Hi,
I'm Djalil.

I'm a computer science student at 42 School in Lyon, obsessed with autonomous systems. The Watcher started as a question: what if two drones could protect a home — patrolling, charging, and handing off, entirely on their own?

Months later, that question became hardware. Drone #1 is built and flying, and with your support on Kickstarter the full system — second drone, charging base, computer vision — comes to life.

Every part of this project is assembled, configured, and coded by me: the airframe, the INAV flight stack, the Raspberry Pi mission software, the charging base. No black boxes — I document everything publicly.

A04 — Honesty

Risks &
challenges.

01

Technical risks

Integrating a flight controller, Raspberry Pi, GPS modules, and a custom charging base into a seamless autonomous system requires extensive testing and iteration. I'll move progressively — basic flight first, full autonomy later.

02

Supply & delivery

Electronic components can face shipping delays or stock issues. I'll order critical parts early and maintain a buffer in the budget for alternatives.

03

Timeline

I'm a solo developer and student. My 6-month timeline is realistic but may shift. I'll communicate any delay immediately and transparently via monthly updates on GitHub.

04

My commitment

I've already built and flown the first drone. The hardware is real, the architecture is designed, the code is in progress. This campaign funds the execution — not the idea.

A05 — FAQ

Questions,
answered.

Will the code be open-source?

Yes — after the campaign, the mission software and charging base code will be published on GitHub under MIT license. No black boxes.

What does backing unlock?

Backing funds the second drone, the autonomous charging base, and the computer vision module. Phase 5 only exists with your support.

What's the timeline?

The Kickstarter campaign is live now. The full two-drone system (Phase 4 complete) is targeted for early 2027, with the CV module to follow if funded.

Is a home surveillance drone even legal?

The Watcher is designed to patrol over your own private property. In the EU, drone flights fall under EASA rules and camera use must respect privacy laws (GDPR) — fully autonomous, out-of-sight flight currently requires specific authorization. I document the regulatory side openly as the project progresses, and backers get honest updates on it like everything else.

Can I follow the build progress?

Absolutely — follow the GitHub org simPly-invent for code updates, and check the Gallery for build log photos.
