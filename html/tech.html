T04 — Core System

The flight
stack.

The heart of The Watcher — INAV on a SpeedyBee F405 V3, tuned by hand, with a Raspberry Pi companion computer running the custom mission layer.

01

Tuned flight control

INAV firmware flashed and configured for The Watcher's exact airframe — Multishot ESC protocol, CRSF receiver link, and hand-tuned flight modes.

Implemented
02

Companion computer

A Raspberry Pi rides onboard, linked to the flight controller over MAVLink (UART2). It will run the surveillance logic, patrol scheduling, and base-station handoff.

Bridge ready
03

Safety systems

Link-loss failsafe set to Land (return-to-home once GPS arrives), low-battery failsafe, and an ARM switch on CH5 — safety first, autonomy second.

Configured
